Speech Audio Authentication
with Frame-Level Tamper Localization

Zero-watermarking — original audio is never modified

A 30-dimensional feature fingerprint (MFCC, ΔMFCC, ZCR, Pitch, Rolloff, RMS) is extracted and encrypted using a Henon map chaotic key. The WAV file stays byte-for-byte identical. BER = 0.0000 on authentic files.

Random Forest classifier — per-frame tamper detection

Trained on 182,588 labeled frames across 4 attack types from the TIMIT corpus. Each 25ms frame is independently classified as authentic or tampered. Achieves 86.28% accuracy and 95.07% recall.

Frame-level localization — tells you exactly where

Instead of a binary yes/no, the system outputs the exact time segment where tampering occurred, shown as a heatmap with tamper probability timeline, BER, and NC scores.
